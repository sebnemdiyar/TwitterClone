## Twitter Clone
Bu proje, kullanıcıların hesap oluşturabildiği, giriş yapabildiği, gönderi (tweet) paylaşabildiği, beğenebildiği ve güncel akışı takip edebildiği modern bir sosyal medya (Twitter/X) klon uygulamasıdır.

## Özellikler
Kullanıcı kimlik doğrulama (Firebase Authentication ile kayıt olma ve giriş yapma)
Anlık veri akışı ve gönderi paylaşımı
Gönderileri beğenme, silme ve düzenleme özellikleri
Toast bildirimleri ile kullanıcı etkileşimlerinde anlık geri bildirimler
Gönderiler için göreceli tarih ve zaman gösterimi (örn. "5 dakika önce")
Responsive ve modern Twitter/X arayüz tasarımı

## Kullanılan Teknolojiler
React Router DOM
React Toastify
React Icons
Tailwind CSS
Firebase
Day.js
UUID
